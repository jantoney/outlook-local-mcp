# Choose the owned Entra app provisioning and validation surface

Labels: `wayfinder:grilling`
Status: open
Blocked by: none

## Question

Given the live audience, token-version, public-client, redirect, and delegated-
permission failure modes observed while configuring the owned Entra app,
should the supported product surface provide documentation only, a read-only
configuration validator, or an automated provisioning/check command; and what
authority, safety, and output boundaries must that choice enforce?
